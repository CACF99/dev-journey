## command lines using bash
> **pwd**: Print Working Directory. Shows the exact folder path of where you are currently standing.
---
> **ls**:List. Shows you all the files and folders inside your current directory.

> **ls -a**: shows hidden files too (like configuration files that start with a dot, e.g., .gitignore).
---
> **cd [folder_name]**: Change Directory. Moves you forward into that folder.
---
> **cd ..**: Moves you backward up one folder level.
---
> **cd**: Takes you straight back to your main Home (~) folder.
---
### Managing Files & Folders (Creating/Deleting) 
> **mkdir [folder_name]**: Make Directory. Creates a brand-new folder.
---
> **rm [file_name]**: Remove. Deletes a file permanently. (Warning: It does not go to the Recycle Bin; it is gone instantly!)
---
> **rm -rf [folder_name]**:Force deletes an entire folder and everything inside it. (Be very careful with this one!)
---
> **mv [old_name] [new_name]**:Move. Used to rename a file/folder or move it to a different location.
### Utility & Workflow Boosters
> **clear**:Wipes the terminal screen clean so you have a fresh workspace (shortcut: Ctrl + L).
---
> **cat [file_name]**:Catenate. Quickly prints the contents of a file right inside the terminal so you can read it without opening an editor.
---
> **history**:Shows a list of all the commands you've typed recently.
---
### Pro-Tips for Git Bash (Keyboard Master)
1.**The Tab Key**: Start typing a file or folder name and hit Tab. Bash will autocomplete the name for you. If it doesn't, tap it twice to see all available options!
2. **The Arrow Keys (Up/Down)**: Press the Up Arrow on your keyboard to cycle through the previous commands you've already typed. Saves a massive amount of re-typing.
