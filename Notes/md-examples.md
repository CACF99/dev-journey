### 2. Common Language Tags
When taking notes for your "Zero to Mastery" course, use these tags to tell VS Code how to color your notes:

* **`html`**: For tags like `<div>`, `<h1>`, etc.
* **`css`**: For styling rules like `.class { color: red; }`.
* **`javascript`** (or **`js`**): For logic, variables, and functions.
* **`bash`**: For terminal commands (like `mkdir` or `git commit`).

---

### 3. The "Inline" Code Trick
Sometimes you don't want a big block; you just want to mention a specific tag or property inside a sentence. For that, use **one backtick** on each side.

**Example:**
"To make text bold in HTML, we use the `<strong>` tag."



---

### 4. Why this is a "Superpower"
When you finish the course, you will have a searchable library of code. If you forget how to make a CSS Grid six months from now, you don't have to re-watch a 20-minute video. You just:
1.  Open your `notes` folder in VS Code.
2.  Press `Ctrl + F` (Find).
3.  Search "Grid."
4.  **Copy and paste** your own perfectly formatted snippet into your new project.
